# 모임 날짜 정하기 (meet-everyday)

친구들과 모임 날짜를 정할 때 단톡방에서 "그날 안 돼", "난 그 주 애매해"가 끝없이 오가는 게 불편해서 만든 웹사이트입니다.
방장이 기간을 정해 링크를 보내면, 각자 **안 되는 날만** 체크하고, 사이트가 결과를 모아 **추천 날짜 TOP 3**를 보여줍니다.

- 배포: Netlify
- 데이터베이스: Firebase Realtime Database (무료 Spark 플랜)
- 프레임워크 없이 HTML/CSS/JavaScript 파일 하나로 구현

## 주요 기능

| 화면 | 기능 |
| --- | --- |
| 모임 만들기 | 모임 이름과 후보 기간(최대 120일)을 정하면 모임 전용 링크 생성 |
| 내 일정 체크 | 이름 입력 후 달력에서 날짜 탭: 1번 = 안됨, 2번 = 애매, 3번 = 취소. 자동 저장 |
| 종합 결과 | 추천 날짜 TOP 3, 안 되는 사람이 많을수록 진해지는 달력, 날짜를 누르면 가능/애매/안됨 명단 |
| 공통 | 실시간 반영(새로고침 없이 다른 사람의 체크가 보임), 링크 복사, 모바일 대응, 다크 모드 |

추천 순서: 안됨 인원이 적은 날 → 애매 인원이 적은 날 → 빠른 날짜 순.

## 기획 과정

1. **문제 정의**: 인원이 늘수록 날짜 조율 메시지가 기하급수적으로 늘어남
2. **기획 결정**
   - 체크 방식: "가능한 날" 대신 **"안 되는 날 + 애매한 날"** 2단계 → 입력 부담 최소화, 체크 안 한 날은 모두 가능으로 간주
   - 날짜 범위: 방장이 기간 지정
   - 결과: 색상 달력 + 추천 TOP 3
   - 요일 제한 없음
3. **디자인 가안 검토 후 구현** (파랑 = 버튼, 빨강 = 안됨, 주황 = 애매, 초록 = 가능)
4. **배포 후 테스트하며 버그 수정**

## 기술 구조

```
index.html              # 화면, 스타일, 로직 전부 (단일 파일)
database.rules.json     # Firebase 보안 규칙
```

### 데이터 구조 (Realtime Database)

```
events
 └ {모임ID}
    ├ meta   { title, start, end, created }
    └ votes
       └ {인코딩된 이름}  { name, marks: { "2026-12-05": 1, "2026-12-12": 2 }, at }
                          # 1 = 안됨, 2 = 애매
```

- 로그인 없이 쓰도록 **링크(모임 ID)를 아는 사람만** 그 모임을 읽고 쓸 수 있는 구조
- 이름을 키로 사용해 다른 기기에서도 같은 이름으로 들어오면 이어서 수정 가능
- Firebase 설정이 비어 있으면 **미리보기 모드**(브라우저 localStorage에만 저장)로 동작

### 보안 규칙 요약

- 모임 정보(`meta`)는 처음 만들 때만 쓰기 가능, 이후 수정 불가
- 참여 기록(`votes`)은 이름이 20자 이하 문자열일 때만 저장
- Firebase 웹 apiKey는 공개용 식별자이며, 실제 접근 제어는 보안 규칙이 담당

## 직접 실행하기

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 생성 → Realtime Database 생성
2. 규칙 탭에 `database.rules.json` 내용 붙여넣고 게시
3. 프로젝트 설정 → 웹 앱 등록 → `firebaseConfig` 값 복사
4. `index.html`의 `firebaseConfig`에 붙여넣기 (`databaseURL` 필수)
5. [Netlify Drop](https://app.netlify.com/drop)에 폴더를 끌어다 놓아 배포

## 개발 중 해결한 문제

- **날짜 입력이 기본값으로 되돌아가는 버그**: 입력칸에서 포커스가 빠질 때마다 화면 전체를 다시 그려 입력값이 초기화됨. 다른 사람의 업데이트가 입력 중에 도착하면 반영을 미뤄두는 `dirty` 플래그를 두고, 미뤄둔 업데이트가 있을 때만 다시 그리도록 수정
- **"불러오는 중…"에서 멈춤**: 설정 붙여넣기 실수로 스크립트 오류가 나도 화면에 아무것도 안 보이던 문제. 전역 오류 핸들러, DB 읽기 실패 콜백, 15초 타임아웃 안내를 추가해 원인이 화면에 표시되도록 개선
- **배포 사이트 접근 불가**: Netlify 방문자 보호(Visitor access)가 켜져 있어 친구들이 로그인 화면을 보게 됨 → 보호 해제
